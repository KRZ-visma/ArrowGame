# ARROW OUT

Vanilla JavaScript arrow-escape puzzle. Click an arrow to slide it off the board in its tip direction — only when nothing blocks the path.

## Play on GitHub Pages

After Pages is enabled for this repo:

**https://krz-visma.github.io/ArrowGame/**

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

## Files

- `index.html` — tiny shell that loads the game
- `game.js` — entire game (UI, styles, levels, logic)

## Controls

Click / tap · Undo · Reset · Skip · `Ctrl/Cmd+Z` · `R`
